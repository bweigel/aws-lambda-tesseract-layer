# ⚠️ DEPRECATION NOTICE

Amazon Linux 2 (AL2) support in this layer is **deprecated** and will be removed in 6 months.

## Action Required

Migrate to Amazon Linux 2023 (AL2023) within the next 6 months.

## Migration Guide

See the [Migration Guide](../../README.md#migration-from-al2-to-al2023) in the main README.

## Timeline

- **Current**: AL2 and AL2023 both supported
- **In 6 months**: AL2 removed, AL2023 only
